---

##  Описание проекта

**VoxEmote: Copilot** — интеллектуальный ассистент оператора колл-центра (сферы ЖКХ, BPO), имитирующий когнитивные функции человека (эмпатию и понимание контекста) для поддержки принятия решений в реальном времени.

**Демо-версия** подтверждает техническую реализуемость ключевого модуля системы — детекции эмоций по речи на базе модели Wav2Vec 2.0.

###  Функции демо-версии:
- Распознавание эмоций по аудиосигналу (3 класса: `neutral`, `stress`, `aggression`)
- REST API для интеграции с внешними системами
- Контейнеризация (Docker) для развёртывания в инфраструктуре заказчика

###  В рамках НИОКР (12 месяцев гранта) планируется добавить:
- Распознавание речи (ASR) на базе Silero V3
- Извлечение именованных сущностей (NER) на базе ruBERT
- Контекстный менеджер (State Manager)
- Генерацию рекомендаций оператору в реальном времени

## 🚀 Быстрый старт

### Требования
- Python 3.10–3.12
- 4 ГБ ОЗУ (минимум)
- Интернет-соединение (для загрузки модели при первом запуске)

### Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/ВАШ_USERNAME/voxemote-demo.git
cd voxemote-demo

# 2. Создать виртуальное окружение
python -m venv venv

# 3. Активировать окружение
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 4. Установить зависимости
pip install -r requirements.txt

# 5. Запустить сервер
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

###  Первый запуск
При первом запуске модель будет загружена с Hugging Face. Это займёт 2–5 минут в зависимости от скорости интернета. Последующие запуски — мгновенные (модель кэшируется).

##  API Endpoints

### `GET /`
Информация о сервисе.

**Ответ:**
```json
{
  "service": "VoxEmote: Copilot Demo",
  "version": "1.0.0",
  "endpoints": {
    "health": "GET /health",
    "predict": "POST /predict_emotion/"
  }
}
```

---

### `GET /health`
Проверка работоспособности API и статуса загрузки модели.

**Ответ:**
```json
{
  "status": "healthy",
  "model_loaded": true,
  "model_name": "superb/wav2vec2-base-superb-er"
}
```

---

### `POST /predict_emotion/`
Распознавание эмоции из аудиофайла.

**Параметры:**
| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `file` | binary | Да | Аудиофайл (WAV/MP3/FLAC, 16 кГц, моно, макс. 10 сек, макс. 10 МБ) |

**Ответ:**
```json
{
  "emotion": "neutral",
  "confidence": 0.989,
  "all_probabilities": {
    "neutral": 0.989,
    "stress": 0.011,
    "aggression": 0.0
  },
  "processing_time_ms": 1573.28
}
```

**Описание полей:**
| Поле | Тип | Описание |
|------|-----|----------|
| `emotion` | string | Доминирующая эмоция (`neutral`, `stress`, `aggression`) |
| `confidence` | float | Уверенность модели (0.0–1.0) |
| `all_probabilities` | object | Вероятности по всем 3 классам |
| `processing_time_ms` | float | Время обработки запроса в миллисекундах |

## 🧪 Тестирование

### Через Swagger UI
Откройте в браузере:
```
http://localhost:8000/docs
```
Нажмите `POST /predict_emotion/` → `Try it out` → выберите файл → `Execute`

### Через curl
```bash
curl -X POST "http://localhost:8000/predict_emotion/" \
  -H "accept: application/json" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@test.wav"
```

### Через Python
```python
import requests

files = {"file": open("test.wav", "rb")}
response = requests.post("http://localhost:8000/predict_emotion/", files=files)
print(response.json())
```

##  Технические характеристики

| Параметр | Значение |
|----------|----------|
| **Модель** | `superb/wav2vec2-base-superb-er` (Hugging Face) |
| **Классы эмоций** | 7 исходных → 3 сгруппированных (neutral/stress/aggression) |
| **Входные данные** | WAV/MP3/FLAC, 16 кГц, моно, макс. 10 сек |
| **Задержка обработки (CPU)** | ~1.5–2.0 сек |
| **Задержка обработки (GPU)** | ~0.3–0.8 сек (ожидаемая) |
| **Точность (целевая)** | ≥78% (требует дообучения на русскоязычных данных ЖКХ) |
| **Стек технологий** | FastAPI, PyTorch, Transformers, librosa, Docker |
